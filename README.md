# Cybernetics Field Guide

An interactive, single-page introduction to cybernetics with working models and real case studies.

- Balancing feedback: a thermostat simulation with gain, delay and a disturbance
- Reinforcing feedback: growth with and without a limiting loop
- Requisite variety: Ashby's law as a live simulation, with triage
- Viable System Model: clickable, with Cybersyn as the worked example
- Second-order cybernetics, eight case files, a timeline and a short quiz

No build step and no dependencies. Open `index.html` in a browser.
