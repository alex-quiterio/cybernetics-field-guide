# Cybernetics Field Guide

A multi-page, interactive introduction to cybernetics with working models, challenges, tools and real case studies. Static site: no build step, no dependencies. Open `index.html` in a browser, or use the [GitHub Pages site](https://alex-quiterio.github.io/cybernetics-field-guide).

| Page | What is on it |
| --- | --- |
| `index.html` | Start: the one loop everything is built from, a "what brings you here?" chooser, and a learning path with saved progress |
| `labs.html` | Four live models (balancing feedback, reinforcing feedback, requisite variety, ultrastability), each with a challenge |
| `orders.html` | First, second and third order cybernetics, a comparison table, a lens explorer, and Gregory Bateson |
| `viable.html` | Stafford Beer's Viable System Model, clickable, plus a seven-question diagnosis of a team you know |
| `atlas.html` | 32 concepts with deeper notes, search and filters, and flashcards |
| `people.html` | 12 people (filterable) and a timeline |
| `cases.html` | Eight real systems taken apart, and a builder for a loop of your own |
| `check.html` | A quiz, a reading list, and every source with what was verified |

Progress is stored in the browser's local storage only. Shared code lives in `assets/` (`style.css`, `common.js`).

Sources and verification notes are on the Check page under Sources.
